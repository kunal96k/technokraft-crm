# Technokraft CRM

Technokraft CRM - Modern Customer Relationship Management and Operations Platform built with React, Vite, and Gemini AI.

View your app in AI Studio: https://ai.studio/apps/d4f19bf1-e592-446f-a0ed-31227fdb0507

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
